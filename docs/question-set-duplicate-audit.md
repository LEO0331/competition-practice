## 方法與限制

- 文字使用Unicode NFKC，移除空白及標點，「臺」與「台」視為排字差異；保留數字、年份、選項順序和答案。
- 精確比對同時檢查題幹、依原順序的四選項及答案；另計只相同題幹的重疊。
- 以雙字元Dice相似度找措辭不同的候選：題幹至少0.8、題幹0.65加權及選項0.35加權總分至少0.85。相似度只作候選提示，不能單獨認定重複；對高重疊配對再檢查不同題目及來源標籤。
- 比對範圍為目前已登錄的選擇題庫；48頁複習筆記、已封存來源版本及尚未提供資料不作另一份作答題庫計算。數值摘要保留移除前的12份題庫快照，便於核對去重決策。
